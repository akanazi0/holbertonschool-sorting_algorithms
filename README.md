# holbertonschool sorting algorithms

A project focused on understanding and implementing sorting algorithms in C, with a strong emphasis on algorithmic thinking, efficiency, and practical coding skills.

## Authors
- Abdulelah Khalaf Alanazi
- Abdullah Anas Almuqbali

## Project Overview
This repository contains implementations of common sorting algorithms and related tasks from the Holberton School curriculum. The goal is to learn how different sorting techniques work, compare their performance, and understand trade-offs in time complexity and memory usage.

## Covered Algorithms
- Bubble sort
- Insertion sort
- Selection sort
- Quick sort


## Learning Objectives
- Understand the behavior and complexity of various sorting algorithms
- Implement sorting logic in C
- Analyze best, average, and worst-case time complexity
- Compare algorithm efficiency and use cases
- Practice writing clean, readable, and well-documented code

## Repository Structure
Each file in this project contains an implementation of a specific sorting algorithm, along with related explanations and examples where needed.

## Requirements
- Ubuntu 20.04 LTS or compatible Linux environment
- GCC compiler
- GNU Make
- C standard library

## Usage
Compile any sorting algorithm file with GCC:

```bash
gcc -Wall -Wextra -Werror -pedantic main.c -o sort
```

Run the executable:

```bash
./sort
```

## Notes
Sorting algorithms are a fundamental concept in computer science. This project helps build a deeper understanding of how data can be ordered efficiently and how algorithm design affects performance.
